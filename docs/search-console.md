# Google Search Console — RankLocal

> A ser detalhado na **Fase 6**, seguindo a regra para APIs Google
> (`docs/architecture.md` §53).

Escopo previsto: OAuth, obtenção de queries/clicks/impressions/CTR/position
por página, módulos de Keywords, Páginas, Oportunidades e Tendências.
Importante: a "position" do Search Console (posição média nos resultados de
busca) nunca deve ser misturada com a "posição observada" do módulo de
Ranking Local (Google Maps) — são métricas de naturezas diferentes.
